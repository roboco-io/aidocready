# 초기 회귀 코퍼스

정본은 `tests/corpus/manifest.json`입니다. 데이터셋 버전은 `2026-10-10.1`이며, 기대 규칙 ID와 블록 위치를 사람이 검토해 고정했습니다. 기대 진단을 lint 실행 결과에서 자동 생성하지 않습니다.

8개 사례 중 하나는 행정안전부 2026-08-24 공식 PDF 3쪽 일정 표의 일부를 Markdown으로 수동 전사한 자료입니다. 출처와 공공누리 제1유형을 manifest에 기록했습니다. 원본 HWPX 전체 또는 셀 병합 정답을 검증하는 자료가 아니라 제목 인식 회귀 사례입니다. 나머지 사례는 합성 Markdown/IR 경계 입력입니다.

검사기는 문서별 누락·예상하지 않은 진단을 다중집합으로 비교합니다. 같은 규칙과 위치가 중복 출력되는 문제도 잡습니다. 검사 누락 상태가 기대값과 달라도 실패합니다. 정상 제목, 누락 제목, 본문 제목 단계, 같은 문단 번호 단계, HTML 미지원, 셀 제목 상태와 단순 병합을 포함합니다.

CI와 Kordoc 업데이트에 이 검사를 연결했습니다. 코퍼스를 확대할 때 정상·위반·판단 보류 사례를 함께 넣고, 출처·이용 조건·기대 위치·검토 이유를 기록하세요. 기대값이나 판정 기준을 바꾸면 데이터셋 버전과 변경 이유를 남깁니다. 이 작은 코퍼스의 통과율을 전체 문서 규칙 정확도나 공식 준수율로 표현하지 않습니다.
