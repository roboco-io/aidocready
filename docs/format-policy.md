# 정보 목적에 따른 형식 선택 정책

이 기준은 aidocready의 자체 보완 정책이다. 행안부 발표의 서술식 작성·구조 명확화 원칙을 적용하되, 공식 지침이 모든 목록이나 표를 금지한다고 해석하지 않는다.

- FMT-PROSE: 배경, 근거, 대안 탈락 이유, 인과관계, 판단과 실패 조건을 연결해 설명할 때 서술형을 우선한다.
- FMT-LIST: 준비물, 확인 항목, 권한, 선택지처럼 독립된 항목을 찾거나 수행하는 것이 목적이면 열거형을 우선한다. 순서·선행 조건이 중요하면 번호 목록, 순서가 없으면 불릿 목록을 쓴다. 존재하지 않는 순서를 만들지 않는다.
- FMT-TABLE: 여러 대상의 동일 속성이나 정확한 값을 행·열로 교차 비교·조회해야 하면 표를 우선한다. 표 제목·순서 표시를 붙이고, 복잡한 병합을 단순화한다. 표가 명확하면 서술형으로 풀어 없애지 않는다.
- FMT-AMBIGUOUS: 용어와 설명처럼 두 속성의 간단한 정보는 목록과 표 모두 가능하다. 독자의 목적, 문장 길이와 화면 조건을 근거로 선택한다. 정해진 하나의 형식으로 억지로 통일하지 않는다.
- FMT-MIXED: 문서 안에서 단락별로 다른 형식을 사용할 수 있다. 판단 근거는 서술형, 대안 비교는 표, 실행 절차는 목록으로 조합한다.
- FMT-FACTS: 형식 선택과 사실 보존은 별개다. 숫자·단위·대상·조건·순서·예외를 유지한다. 빠진 값을 추정하거나 계산으로 채우지 말고 미제공임을 표시하고 필요한 질문을 남긴다.
- FMT-USER: 사용자가 특정 형식을 명시한 경우 그 요구를 우선하되, 표현에 한계가 있으면 설명한다. 정적 lint 통과를 의미 보존이나 형식 적합성의 보증으로 주장하지 않는다.

에이전트는 선택한 형식, 독자가 수행할 읽기 작업, 대안 형식보다 적합하다고 판단한 이유를 설명한다. 이는 평가 가능한 선택 근거이며 내부 추론 과정을 요구하는 것이 아니다.
