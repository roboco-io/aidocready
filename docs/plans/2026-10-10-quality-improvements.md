# AI Doc Ready 품질 개선 실행 계획

승인된 개선 제안을 순서대로 구현한다. 기존 Node.js 20, Kordoc 의존성, 원문 보존 및 공식/자체 규칙 구분을 유지한다.

1. 제목 존재/순서 표시 분리, 컨테이너별 제목 상태, 게시된 스킬 안내와 버전 정본.
2. 독립 기대 진단을 가진 회귀 코퍼스 및 CI/업스트림 게이트.
3. 오류 원인과 규칙별 검사 상태, 원본 위치·발췌·도움말 계약.
4. 검증된 사용자 프로파일 로더와 메타데이터 드리프트 게이트.
5. lintFile 공개 API, npm tarball 소비자 테스트와 CI.
6. CLI의 여러 파일·디렉터리 입력, 출력 파일, 상태 확인과 설치 안내.
7. 경량 설치/오프라인 운영 문서와 입력 자원 한도.

각 구현은 실패하는 테스트 → 수정 → 전체 검증을 거친다. 묶음별로 커밋하고 최종 독립 리뷰를 수행한다. npm 재게시는 이번 작업 범위에 포함하지 않고 GitHub에 검증된 변경을 반영한다.

원문 비교(compare)는 앞선 제안에서 후속 기능으로 분리했으므로 위 검사 품질 개선 후 별도 설계로 진행한다.

## 완료 기록

- 단계 1–7 구현 완료. 개선을 논리별 커밋으로 분리했다.
- 독립 리뷰에서 출력 하드링크 보호, 일부 경로 오류 이후 일괄 검사 유지, 프로파일 오류 타입을 수정했다. 각 문제는 실패하는 회귀 테스트를 확인한 뒤 수정했다.
- 디렉터리 결과 형식은 파일 개수와 관계없이 일괄 envelope로 유지했다.
- 네이티브 HWPX 캡션의 제목 존재도 Markdown 표기 문법과 분리했다.
- 최종 자동 테스트 77개 및 초기 회귀 사례 8개 통과. 타입·빌드·메타데이터·Actions 정적 검사와 깨끗한 npm 설치 소비자 검사 통과.
- 버전은 0.2.0 개발본으로 준비했다. npm 게시는 수행하지 않았다.

제한: 회귀 코퍼스는 작은 초기 자료이며 전체 실문서 정확도 검증이 아니다. setup은 기존 설정을 수정하지 않는 안내 명령이다. 원문 의미 비교 및 에디터 SARIF 연동은 후속 기능이다.
