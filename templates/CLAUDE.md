# 보고서 작성 정책

보고서 작성·수정 요청에는 aidocready 스킬이 있으면 사용한다. 스킬이 없으면 아래 원칙과 로컬 CLI를 직접 사용한다. 코드·설정·일반 대화에는 적용하지 않는다.

- 원문의 수치, 단위, 날짜, 조건, 주체와 의미를 보존한다. 원문에 없는 수치·계산 결과·해석을 추가하지 않는다.
- 표·그림 위에 제목과 순서 표시를 둔다. 표는 필요하면 유지한다. 셀 병합을 단순하게 한다.
- 서술식 문장을 사용한다. 항목 표시를 일관되게 쓴다. 장식 목적으로 표를 만들지 않는다.
- 공식 원칙과 aidocready 자체 보완 규칙을 구분한다.
- 로컬 패키지를 빌드한 뒤 패키지 디렉터리에서 `node dist/cli.js lint <파일의 절대 경로> --format json --fail-on Warning`을 실행한다.
- 작성 → lint → 원문 대조 → 필요한 수정 → 재검사를 반복한다. 변경 이유와 남은 수동 검토 사항을 보고한다.
- 종료 코드 1은 진단 또는 검사 누락이다. 2는 실행 오류다. 원인을 확인하고 재실행한다.
- lint 통과를 의미·사실 보존 또는 행안부 공식 인증이라고 표현하지 않는다.
- 기존 AGENTS.md를 덮어쓰지 않고 이 정책을 필요한 범위에 합친다.
