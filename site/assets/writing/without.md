# 민원 접수 알림 방식 개선안

## 추진 배경과 목표

- 현재 안내: 온라인 민원 접수 완료 화면만 제공
- 이용 상황: 화면을 닫은 뒤 접수 여부를 확인하려는 전화 문의 반복
- 목표: 접수 사실의 재확인 지원, 접수 여부 확인 전화 감소
- 범위: 접수 안내 개선. 민원 처리 기간 단축이나 처리 결과 통지는 제외

## 대안 검토와 선택

- 완료 화면 개선: 기존 조회 경로 유지 가능 / 화면을 닫은 뒤 별도 안내 불가 → 단독 대안으로는 부족
- 이메일 안내: 대상 이용자 중 이메일 주소 미등록자 존재 → 전체 시범 대상의 기본 수단으로는 부적합
- 문자 안내: 휴대전화 번호 등록 및 문자 수신 신청 이용자에게 제공 가능 → 해당 이용자에 한해 선택
- 수신 미신청·번호 미등록 이용자: 기존 완료 화면과 접수 조회 경로 유지
- 발송 비용: 문자 방식의 추가 부담 / 운영책임자의 비용 한도 승인 후 시범 운영

## 운영 원칙과 예외 처리

- 접수 확정 기준: 접수 시스템의 저장 완료
- 문자 발송 실패: 접수 취소·재접수 요구 금지. 접수 상태와 발송 상태 분리
- 발송 실패 건: 확인 대기 목록 등록 → 민원팀이 다음 영업일 확인
- 같은 접수 건: 자동 중복 발송 금지
- 문자 내용: 접수번호와 조회 방법만 포함. 민원 내용·민감정보 제외

## 시범 운영과 역할

- 적용 범위: 민원 한 종류, 문자 수신 신청 및 번호 등록 이용자
- 정보화팀: 발송 연동 구현, 접수·발송 상태 분리, 실패 기록 제공
- 민원팀: 안내 문구 검토, 실패 건 확인, 전화 문의 유형 기록
- 운영책임자: 발송 비용 한도 승인, 시범 운영 평가, 확대 여부 결정
- 확인 자료: 발송 성공 여부, 실제 발송 비용, 접수 여부 확인 전화의 유형

## 확대·중단 판단

- 문의 감소: 현재 미확인. 시범 기록을 보고 판단
- 확대 조건: 잘못된 안내·중복 발송의 재발 방지 확인 + 추가 비용 승인 → 운영책임자 결정
- 중단 조건: 잘못된 안내·중복 발송 발생 또는 승인 비용 한도 초과 → 신규 문자 발송 중단, 원인 점검
- 중단 시: 완료 화면과 접수 조회 기능 유지. 기존 접수는 유효
