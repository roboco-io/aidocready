# 민원 접수 알림 방식 개선안

## 추진 배경과 목표

현재 온라인 민원은 접수 완료 화면으로만 접수 사실을 안내한다. 이용자가 이 화면을 닫은 뒤 접수 여부를 다시 확인하려고 전화하는 상황이 반복되므로, 접수 사실을 재확인할 수 있는 안내 수단을 추가하려 한다. 목표는 접수 여부 확인 전화를 줄이는 것이다. 이번 개선은 접수 안내에 한정하며, 민원 처리 기간 단축이나 처리 결과 통지는 포함하지 않는다.

## 대안 검토와 선택

완료 화면을 개선하면 기존 조회 경로를 유지할 수 있지만, 화면을 닫은 이용자에게 별도로 안내할 수 없으므로 단독 대안으로는 부족하다. 이메일도 검토했으나 대상 이용자 중 주소 미등록자가 있어 전체 시범 대상의 기본 수단으로 삼기 어렵다. 따라서 휴대전화 번호를 등록하고 문자 수신을 신청한 이용자에게 문자 안내를 제공하는 방식을 선택한다. 신청하지 않았거나 번호를 등록하지 않은 이용자는 기존 완료 화면과 접수 조회 경로를 이용한다. 다만 문자에는 발송 비용이 추가되므로, 운영책임자가 비용 한도를 승인한 뒤에 시범 운영을 시작한다.

## 운영 원칙과 예외 처리

문자는 접수 사실을 알려주는 수단이며, 접수가 확정되는 기준은 접수 시스템의 저장 완료다. 따라서 문자 발송에 실패하더라도 접수를 취소하거나 이용자에게 재접수를 요구하지 않도록 접수 상태와 발송 상태를 분리한다. 실패 건은 확인 대기 목록에 남기고 민원팀이 다음 영업일에 확인하며, 같은 접수 건을 자동 중복 발송하지 않는다. 문자에는 접수번호와 조회 방법만 넣고 민원 내용과 민감정보는 포함하지 않는다.

## 시범 운영과 역할

시범 운영은 민원 한 종류에서 문자 수신을 신청하고 번호를 등록한 이용자를 대상으로 진행한다. 정보화팀은 발송 연동과 상태 분리를 구현하고 실패 기록을 제공한다. 민원팀은 안내 문구를 검토하고 실패 건을 확인하며 전화 문의 유형을 기록한다. 운영책임자는 비용 한도를 승인하고, 발송 성공 여부·실제 발송 비용·접수 여부 확인 전화의 유형을 근거로 시범 운영을 평가해 확대 여부를 결정한다.

## 확대·중단 판단

전화 문의가 줄어드는지는 아직 확인하지 못했으므로 시범 기록을 보고 판단해야 한다. 확대는 잘못된 안내와 중복 발송의 재발 방지가 확인되고 추가 비용이 승인된 뒤에 운영책임자가 결정한다. 반대로 잘못된 안내나 중복 발송이 발생하거나 승인 비용 한도를 넘으면 신규 문자 발송을 중단하고 원인을 점검한다. 이때도 이용자가 접수 사실을 확인할 수 있도록 완료 화면과 접수 조회 기능을 유지하며, 이미 접수된 민원은 유효하게 남긴다.
