# 발송 실패 대응 시 확인할 사항

표 1. 발송 실패 대응 시 확인할 사항

| 구분 | 확인할 내용 |
| --- | --- |
| 접수 상태 | 저장이 완료된 접수는 유효하게 유지한다. 문자 발송 실패를 이유로 취소하거나 재접수를 요구하지 않는다. |
| 실패 건 관리 | 발송 실패 건을 확인 대기 목록에 등록한다. |
| 확인 담당·시점 | 민원팀이 다음 영업일에 실패 건을 확인한다. |
| 중복 발송 방지 | 같은 접수 건은 자동 중복 발송하지 않는다. |
| 발송 중단 조건 | 잘못된 안내·중복 발송이 발생하거나 승인 비용 한도를 초과하면 신규 문자 발송을 중단하고 원인을 점검한다. |
| 조회 기능 유지 | 문자 발송 중단 시에도 완료 화면과 접수 조회 기능을 유지한다. |
