AI Doc Ready {{VERSION}} 공개,
보고서의 AI 친화적 구조를 로컬에서 점검

Markdown·HWPX 작성자와 AI 에이전트가 같은 검사 규칙으로 초안을 검토하고 수정할 수 있도록 지원

{{RELEASE_DATE}} · roboco-io

보도자료 다운로드제품 FAQ

roboco-io는 AI 친화적 보고서의 구조를 검사하는 오픈소스 도구 AI Doc Ready {{VERSION}}을 npm에 공개했다. Markdown과 HWPX 문서의 표·그림 제목, 순서 표시, 항목 단계, 중첩 표와 셀 병합 검토 후보를 확인하고, 작성자가 살펴볼 위치와 판단 근거를 제공한다.

이 프로젝트는 행정안전부의 AI 친화적 보고서 전면 도입 발표를 계기로 시작됐다. 보고서의 내용을 AI가 이해하기 쉬운 구조로 작성하는 원칙을, 작성 도구가 달라도 재현 가능한 검사 결과로 활용하는 데 목적을 두었다.

사용자는 Node.js 20 이상 환경에서 npx aidocready@{{VERSION}} lint report.md를 실행해 문서를 검사할 수 있다. {{VERSION}}은 여러 파일과 디렉터리, JSON 결과 파일, 사용자 프로파일, 규칙별 검사 상태와 공개 라이브러리 API를 제공한다. SKILL.md와 상시 지침 템플릿으로 Codex·Claude Code·pi의 작성→검사→수정 흐름에 연결할 수 있다.

문서 파싱에는 Kordoc을 라이브러리 의존성으로 사용한다. 정적 lint는 로컬에서 실행하고 원본을 수정하지 않는다. 공식 발표를 근거로 한 원칙과 프로젝트의 자체 보완 규칙을 구분하며, 문장 명확성과 사실·수치·의미 보존은 원문 대조와 사람의 최종 검토가 필요하다.

AI Doc Ready는 MIT 라이선스로 제공한다. 소스 코드, 사용 매뉴얼과 예제는 공개 저장소와 제품 페이지에서 확인할 수 있으며, 사용 중 발견한 문제와 기능 제안은 GitHub Issues로 제출할 수 있다.
