같은 샘플로 직접 실행하세요

hwp2md는 아래 고정 커밋으로 빌드했습니다. 내장 파서의 Stage 1만 사용했고 LLM과 외부 문서 API는 호출하지 않았습니다. 기존 hwp2md 설정의 llm.enabled도 false인지 확인하세요.

hwp2md convert original.hwpx --parser native --llm=false -o converted.md
npx aidocready@{{VERSION}} lint converted.md --format json --output lint.json

검사는 이 페이지에서 파일을 올려 실행하는 방식이 아닙니다. 공개 샘플로 실행해 저장한 결과를 보여줍니다. 변경 없는 원본·변환 파일·검사 JSON과 실행 기록·SHA-256을 제공합니다.
